# Cleaning log

Counts come from `notebooks/02_clean.ipynb` (run 2026-11-06).

1. **Merge TGA exports.** Skipped the preamble lines, took the header at `"ARTG ID"`, converted column names to snake_case, dropped `phone`. Archived rows end with an extra comma, so the file is read with `index_col=False` (otherwise columns shift). Active 1,044 + archived 9,697 = 10,741 rows. Reason: the exports have different columns and a free-text preamble.
2. **Parse dates as d/mm/yyyy.** 0 unparsed values in the four date columns. Reason: explicit format avoids day/month confusion.
3. **Derive `episode_type`.** `discontinuation` if `deletion_from_market` exists, otherwise `current`/`anticipated` from `shortage_status`, `resolved` if an end date exists, else `unknown`. Result after step 4: active anticipated 91, current 448, discontinuation 293, resolved 212; archived discontinuation 1,591, resolved 8,086, unknown 1. One active row labelled Resolved has a deletion date and is classed as discontinuation. Reason: 100 of the 138 rows with both end and deletion dates have deletion before end, so the end date there appears to be a planned date (official meaning not verified).
4. **Remove superseded duplicates.** Rows sharing `artg_id` + start date + `episode_type` are collapsed to the one with the latest end date: 19 archived rows removed (16 resolved, 3 discontinuation); 10,741 -> 10,722 rows. Reason: the archived export has no version column. No active Resolved row duplicates an archived row (0 of 213).
5. **Flag date anomalies instead of deleting rows.** `end_lt_start`: 1 resolved + 4 discontinuation rows; `end_after_report` (end after 2026-11-06): 2 resolved + 4 discontinuation rows (current and anticipated rows legitimately end later). Only resolved rows with end >= start and end <= 2026-11-06 get `duration_days`: 8,295 of 8,298 (Critical 747, High 103, Medium 2,403, Low 5,042). Reason: protects H2 from impossible durations.
6. **Keep 11 active Current rows whose end date has already passed**, flagged `end_passed`. Reason: TGA status is the primary field.
7. **Missing values.** 1 row without `active_ingredients` (flag `no_ingredient`, excluded from ingredient analysis); 1 row without `artg_name` (kept).
8. **PBS DOS files.** Concatenated 389,050 + 399,848 = 788,898 rows, 24 months (202407-202606), 0 duplicate keys. Item map: read with `latin-1` because UTF-8 decoding failed; `DRUG_NAME` upper-cased and whitespace-normalised (445 names changed); 12,245 unique `ITEM_CODE`.
9. **Keep public hospitals only** (`PHRMCY_TYPE == "S94 PUB"`, confirmed in PBS explanatory notes): 164,292 rows, 3,656,321 prescriptions. Rows without a drug name (items `00000B` and `99999Z`, 80 rows, 149 prescriptions) dropped. Reason: the scope is public hospital usage; `99999Z` is the generic code for unlisted RPBS-only items per the PBS notes, `00000B` is not explained there.
10. **Exclude months 202605 and 202606:** 14,080 rows, 290,710 prescriptions. Reason: PBS states recent months are less complete and the report is not for recent trends.
11. **Drop non-drug preparations** (names whose items all have ATC5 starting with Z): only `EXTEMPORANEOUSLY PREPARED` appears in the public data, 22 rows, 1,908 of 3,365,474 prescriptions.
12. **Normalise ingredient names on both sides into `ingredient_key`.** Remove salts/hydrates (including words such as medoxomil, cilexetil, besilate), remove bracketed text and `ACID TARTRATE`, treat `~`, `(&)` and `+` as the same separator, sort components, map `CLAVULANATE` to `CLAVULANIC ACID`. Reason: TGA uses salt forms and `~`, PBS uses generic names and `+`.
13. **Match rate TGA -> PBS.** Exact string match before normalisation: 405 of 1,351 distinct TGA strings (30.0%). After normalisation: 916 strings (67.8%) match the PBS item map and 684 (50.6%) have S94 PUB usage in the window. By episode (10,721 with an ingredient): 9,116 (85.0%) match the map and 7,915 (73.8%) have S94 PUB usage. By distinct key: 698 of 1,048 in the map, 489 with usage.
14. **Accepted merges.** 8 PBS keys combine more than one `DRUG_NAME` (for example betamethasone, hydrocortisone, metoprolol, erythromycin). Reason: analysis is at active-ingredient level.
15. **Unmatched remainder is not forced.** 350 keys / 1,605 episodes: 248 keys (1,241 episodes) have no PBS name sharing the first component (reason not verified, for example medicines outside the PBS data); 102 keys (364 episodes) are mostly combinations where PBS lists only one component. They are treated as "usage not measurable", not zero usage. A further 1,201 episodes match the map but have no S94 PUB usage in the window.
